# Settings, Account Deletion & Logout Polish Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A rich, on-theme Settings area (account, preferences incl. languages, interview, notifications, privacy & data, accessibility, billing), complete account deletion across every data store, data export, and an on-theme replacement for the profile's "Log out" link.

**Architecture:**
- **API.** The API gains a `/users/me` account router:
  - preferences in a new Mongo `user_preferences` collection, overlaid leaf-by-leaf on defaults;
  - display name, revoke-all-sessions, JSON export;
  - an `AccountDeletionService` that purges the AI service first, then API Mongo, then Postgres in one transaction (user row last, so retries are safe).
- **AI service.** Gets an internal `POST /users/purge`.
- **Web.** A `features/settings` data layer (optimistic preference mutations, device-only prefs in localStorage). Settings pages under `app/(app)/settings/**` are built on the HUD primitives (`@/components/hud`).

**Tech Stack:** Express 5 + zod 4 + Drizzle (PGlite in tests) + MongoDB driver (mongodb-memory-server in tests); FastAPI + Motor (pytest); Next.js 16 / React 19 / Tailwind 3 / Radix (shadcn) / TanStack Query v5 / sonner / Vitest + RTL; Playwright for screenshots.

**Spec:** `docs/superpowers/specs/2026-10-02-settings-design.md`

## Review Focus

1. **Rename, then Google sign-in again.** Today `upsertByGoogleSub` overwrites `name` on every Google login, which would silently undo the user's new display name. Expect the chosen name to survive. Pinned in Task 3: "a later Google sign-in keeps the renamed display name".
2. **Two preference toggles in flight at once.** The first PATCH response must not overwrite the second toggle's optimistic value in the cache. Pinned in Task 8: `useUpdatePreferences` keeps the optimistic state while another save is pending.
3. **A stored preference holding a stale or invalid value** (an enum option removed later, a bad timezone). GET must return the default for that leaf, not 500 or echo garbage. Pinned in Task 1: `resolvePreferences` falls back per leaf.
4. **Retrying a half-finished deletion** (Mongo docs gone, Postgres rows left after a crash). A second DELETE must still succeed and finish the wipe. Pinned in Task 6: "a retry after a partial wipe finishes the job".
5. **Settings at phone width (≈390px).** Three-option segmented controls and the notification grid must wrap or stack, never overflow horizontally. Pinned in Task 16: the screenshot script asserts `scrollWidth <= innerWidth` on every settings page at 390px.

```ts
import { z } from "zod";
import { BadRequestError } from "../lib/errors.js";

/**
 * Account-level settings (Settings → Preferences / Interview / Notifications / Privacy).
 *
 * Mongo `user_preferences` stores only what the user changed. Reads overlay that on
 * DEFAULT_PREFERENCES leaf by leaf, so adding a setting later needs no migration and a stale stored
 * value (an option removed since) falls back to its default instead of breaking the read.
 * Device-only settings (theme, reduced motion, text size) never reach the server.
 */

export const APP_LANGUAGES = ["en", "hi", "ta", "te", "bn", "mr"] as const;
export const DATE_FORMATS = ["DD/MM/YYYY", "MM/DD/YYYY", "YYYY-MM-DD"] as const;
export const TIME_FORMATS = ["12h", "24h"] as const;
export const WEEK_STARTS = ["monday", "sunday"] as const;
export const INTERVIEW_LANGUAGES = ["en", "hinglish", "hi"] as const;
export const INTERVIEWER_VOICES = ["warm", "neutral", "crisp"] as const;
export const SPEAKING_PACES = ["slower", "normal", "faster"] as const;
export const REMINDER_LEADS = ["15m", "1h", "1d"] as const;
export const LEADERBOARD_VISIBILITY = ["name", "anonymous", "hidden"] as const;
export const NOTIFICATION_TOPICS = [
  "interviewReminders",
  "debriefReady",
  "retakeAvailable",
  "targetOpenings",
  "weeklyDigest",
  "productUpdates",
] as const;

function isTimeZone(tz: string): boolean {
  try {
    new Intl.DateTimeFormat("en-US", { timeZone: tz });
    return true;
  } catch {
    return false;
  }
}

const timeZone = z.string().max(64).refine(isTimeZone, { error: "Unknown timezone." });

const channel = z.object({
  interviewReminders: z.boolean(),
  debriefReady: z.boolean(),
  retakeAvailable: z.boolean(),
  targetOpenings: z.boolean(),
  weeklyDigest: z.boolean(),
  productUpdates: z.boolean(),
});

const locale = z.object({
  appLanguage: z.enum(APP_LANGUAGES),
  /** IANA zone, or null = follow the browser ("Automatic"). */
  timezone: timeZone.nullable(),
  dateFormat: z.enum(DATE_FORMATS),
  timeFormat: z.enum(TIME_FORMATS),
  weekStart: z.enum(WEEK_STARTS),
});

const interview = z.object({
  language: z.enum(INTERVIEW_LANGUAGES),
  voice: z.enum(INTERVIEWER_VOICES),
  pace: z.enum(SPEAKING_PACES),
  captions: z.boolean(),
  showTimer: z.boolean(),
  deviceCheck: z.boolean(),
  reminderLead: z.enum(REMINDER_LEADS),
});

const notifications = z.object({ emailPaused: z.boolean(), email: channel, inApp: channel });

const privacy = z.object({
  leaderboardVisibility: z.enum(LEADERBOARD_VISIBILITY),
  shareWithCollege: z.boolean(),
  partnerDiscovery: z.boolean(),
  improveWithMyData: z.boolean(),
});

export const PreferencesSchema = z.object({ locale, interview, notifications, privacy });
export type Preferences = z.infer<typeof PreferencesSchema>;

/** A PATCH body: any subset of leaves. Unknown keys anywhere are rejected. */
const PreferencesPatchSchema = z
  .object({
    locale: locale.partial().strict().optional(),
    interview: interview.partial().strict().optional(),
    notifications: z
      .object({
        emailPaused: z.boolean().optional(),
        email: channel.partial().strict().optional(),
        inApp: channel.partial().strict().optional(),
      })
      .strict()
      .optional(),
    privacy: privacy.partial().strict().optional(),
  })
  .strict();
export type PreferencesPatch = z.infer<typeof PreferencesPatchSchema>;

/** Privacy-first product defaults (spec §3.1). */
export const DEFAULT_PREFERENCES: Preferences = {
  locale: { appLanguage: "en", timezone: null, dateFormat: "DD/MM/YYYY", timeFormat: "12h", weekStart: "monday" },
  interview: { language: "en", voice: "neutral", pace: "normal", captions: true, showTimer: true, deviceCheck: true, reminderLead: "1h" },
  notifications: {
    emailPaused: false,
    email: { interviewReminders: true, debriefReady: true, retakeAvailable: true, targetOpenings: true, weeklyDigest: true, productUpdates: false },
    inApp: { interviewReminders: true, debriefReady: true, retakeAvailable: true, targetOpenings: true, weeklyDigest: false, productUpdates: false },
  },
  privacy: { leaderboardVisibility: "anonymous", shareWithCollege: false, partnerDiscovery: false, improveWithMyData: false },
};

export function parsePreferencesPatch(body: unknown): PreferencesPatch {
  const r = PreferencesPatchSchema.safeParse(body);
  if (r.success) return r.data;
  const issue = r.error.issues[0];
  const where = issue ? issue.path.map(String).join(".") : "";
  const message = issue?.message ?? "Invalid preferences.";
  throw new BadRequestError(where ? `${where}: ${message}` : message, "invalid_preferences");
}

const isRecord = (v: unknown): v is Record<string, unknown> => typeof v === "object" && v !== null && !Array.isArray(v);

/** Walk the schema: objects recurse, leaves keep the stored value only if it still validates. */
function overlay(schema: z.ZodType, fallback: unknown, stored: unknown): unknown {
  if (schema instanceof z.ZodObject) {
    const src = isRecord(stored) ? stored : {};
    const base = fallback as Record<string, unknown>;
    return Object.fromEntries(
      Object.entries(schema.shape as Record<string, z.ZodType>).map(([key, child]) => [key, overlay(child, base[key], src[key])]),
    );
  }
  return schema.safeParse(stored).success ? stored : fallback;
}

export function resolvePreferences(stored: unknown): Preferences {
  return overlay(PreferencesSchema, DEFAULT_PREFERENCES, stored) as Preferences;
}

/** `{ locale: { timezone: null } }` → `{ "locale.timezone": null }`, for a Mongo `$set`. */
export function toSetPaths(patch: PreferencesPatch): Record<string, unknown> {
  const out: Record<string, unknown> = {};
  const walk = (obj: Record<string, unknown>, prefix: string) => {
    for (const [key, value] of Object.entries(obj)) {
      if (value === undefined) continue;
      const path = prefix ? `${prefix}.${key}` : key;
      if (isRecord(value)) walk(value, path);
      else out[path] = value;
    }
  };
  walk(patch as Record<string, unknown>, "");
  return out;
}
```

```ts
import type { UserPreferencesRepository } from "../repositories/mongo.js";

/** The wire shape: every setting resolved, plus when the user last changed one (null = never). */
export type PreferencesResponse = Preferences & { updatedAt: string | null };

export class PreferencesService {
  constructor(private readonly repo: UserPreferencesRepository) {}

  async get(userId: string): Promise<PreferencesResponse> {
    const doc = await this.repo.findByUserId(userId);
    return { ...resolvePreferences(doc), updatedAt: doc ? doc.updatedAt.toISOString() : null };
  }

  /** Validate a partial patch (400 invalid_preferences), persist only its leaves, return the full set. */
  async update(userId: string, body: unknown): Promise<PreferencesResponse> {
    const paths = toSetPaths(parsePreferencesPatch(body));
    if (Object.keys(paths).length === 0) return this.get(userId);
    const doc = await this.repo.setPaths(userId, paths, new Date());
    return { ...resolvePreferences(doc), updatedAt: doc.updatedAt.toISOString() };
  }
}
```

```ts
import type { CandidateProfileDoc } from "../db/mongo/client.js";
import type { InterviewSessionRow } from "../db/pg/schema.js";
import type { CandidateProfileRepository, ProfileFragmentRepository, SessionOutcomeRepository } from "../repositories/mongo.js";
import type {
  GitHubConnectionRepository,
  InterviewSessionRepository,
  LeetCodeConnectionRepository,
  UserRepository,
} from "../repositories/pg.js";
import type { PreferencesResponse, PreferencesService } from "./preferencesService.js";
import { toUserResponse, type UserResponse } from "./userService.js";

const PLANS_NOTE = "Interview plans generated by the AI service are not included in this export.";

export interface AccountExport {
  exportedAt: string;
  notes: string[];
  user: UserResponse & { createdAt: string };
  preferences: PreferencesResponse;
  candidateProfile: Omit<CandidateProfileDoc, "_id"> | null;
  connections: {
    github: { login: string; scope: string; connectedAt: Date; lastRefreshedAt: Date | null; status: string | null } | null;
    leetcode: { username: string; status: string; connectedAt: Date; lastRefreshedAt: Date | null } | null;
  };
  profileFragments: { source: string; data: Record<string, unknown>; version: number; fetchedAt: Date }[];
  interviewSessions: InterviewSessionRow[];
  sessionOutcomes: { sessionId: string; outcome: Record<string, unknown>; receivedAt: Date }[];
}

function withoutId<T extends { _id: unknown }>(doc: T): Omit<T, "_id"> {
  const copy: Partial<T> = { ...doc };
  delete copy._id;
  return copy as Omit<T, "_id">;
}

/** "Export my data": everything this API stores about the user, minus secrets (hashes, tokens, Google subject). */
export class AccountExportService {
  constructor(
    private readonly users: UserRepository,
    private readonly preferences: PreferencesService,
    private readonly candidateProfiles: CandidateProfileRepository,
    private readonly github: GitHubConnectionRepository,
    private readonly leetcode: LeetCodeConnectionRepository,
    private readonly fragments: ProfileFragmentRepository,
    private readonly sessions: InterviewSessionRepository,
    private readonly outcomes: SessionOutcomeRepository,
  ) {}

  async export(userId: string): Promise<AccountExport | null> {
    const user = await this.users.findById(userId);
    if (!user) return null;
    const [preferences, profile, github, leetcode, fragments, sessions] = await Promise.all([
      this.preferences.get(userId),
      this.candidateProfiles.findByUserId(userId),
      this.github.findByUserId(userId),
      this.leetcode.findByUserId(userId),
      this.fragments.findByUserId(userId),
      this.sessions.findAllByCandidateIdOrderByScheduledAtDesc(userId),
    ]);
    const outcomes = await this.outcomes.findBySessionIds(sessions.map((s) => s.id));

    return {
      exportedAt: new Date().toISOString(),
      notes: [PLANS_NOTE],
      user: { ...toUserResponse(user), createdAt: user.createdAt.toISOString() },
      preferences,
      candidateProfile: profile ? withoutId(profile) : null,
      connections: {
        github: github
          ? { login: github.githubLogin, scope: github.scope, connectedAt: github.connectedAt, lastRefreshedAt: github.lastRefreshedAt, status: github.status }
          : null,
        leetcode: leetcode
          ? { username: leetcode.username, status: leetcode.status, connectedAt: leetcode.connectedAt, lastRefreshedAt: leetcode.lastRefreshedAt }
          : null,
      },
      profileFragments: fragments.map((f) => ({ source: f.source, data: f.data, version: f.version, fetchedAt: f.fetchedAt })),
      interviewSessions: sessions,
      sessionOutcomes: outcomes.map((o) => ({ sessionId: o._id, outcome: o.outcome, receivedAt: o.receivedAt })),
    };
  }
}
```

```ts
import type { Database } from "../db/pg/client.js";
import type { AiServiceClient } from "../integrations/aiService/client.js";
import type { GitHubOAuthService } from "../integrations/github/oauth.js";
import { errorMessage } from "../lib/errors.js";
import type { Logger } from "../lib/logger.js";
import { verifyPassword } from "../lib/password.js";
import type {
  CandidateProfileRepository,
  ProfileFragmentRepository,
  SessionOutcomeRepository,
  UserPreferencesRepository,
} from "../repositories/mongo.js";
import type { GitHubConnectionRepository, InterviewSessionRepository, UserRepository } from "../repositories/pg.js";

export class ConfirmationMismatchError extends Error {}
export class InvalidPasswordError extends Error {}
export class InterviewInProgressError extends Error {}
export class DeletionUnavailableError extends Error {}

/** The AI service's purge accepts at most this many session ids per call. */
const PURGE_BATCH = 1000;

export interface AccountDeletionDeps {
  users: UserRepository;
  sessions: InterviewSessionRepository;
  githubConnections: GitHubConnectionRepository;
  candidateProfiles: CandidateProfileRepository;
  fragments: ProfileFragmentRepository;
  outcomes: SessionOutcomeRepository;
  preferences: UserPreferencesRepository;
  aiService: AiServiceClient;
  githubOAuth: GitHubOAuthService;
  log: Logger;
}

/**
 * "Delete account": an immediate hard delete of everything we hold about the user.
 *
 * Order matters:
 *  1. Checks (typed email, password, no live interview). Nothing is touched if any fails.
 *  2. The AI service (interview plans). A failure aborts BEFORE anything local is deleted.
 *  3. The GitHub grant, best effort.
 *  4. The API's Mongo documents.
 *  5. Postgres in one transaction, user row last.
 * Every step is idempotent and the user row goes last, so a crash mid-way leaves an account that
 * can sign in and simply retry.
 */
export class AccountDeletionService {
  constructor(private readonly d: AccountDeletionDeps) {}

  /** False when the user doesn't exist (already deleted). */
  async delete(userId: string, input: { confirmEmail: string; password?: string }): Promise<boolean> {
    const user = await this.d.users.findById(userId);
    if (!user) return false;

    if (input.confirmEmail.trim().toLowerCase() !== user.email.toLowerCase()) throw new ConfirmationMismatchError();
    if (user.passwordHash !== null && !(input.password && (await verifyPassword(input.password, user.passwordHash)))) {
      throw new InvalidPasswordError();
    }

    const sessions = await this.d.sessions.findAllByCandidateIdOrderByScheduledAtDesc(userId);
    if (sessions.some((s) => s.status === "LIVE_IN_PROGRESS")) throw new InterviewInProgressError();
    const sessionIds = sessions.map((s) => s.id);

    try {
      for (let i = 0; i < sessionIds.length; i += PURGE_BATCH) {
        await this.d.aiService.purgeUser(sessionIds.slice(i, i + PURGE_BATCH));
      }
    } catch (err) {
      this.d.log.warn({ err: errorMessage(err) }, `account deletion aborted: AI service purge failed userId=${userId}`);
      throw new DeletionUnavailableError();
    }

    const github = await this.d.githubConnections.findByUserId(userId);
    if (github) {
      try {
        await this.d.githubOAuth.revokeGrant(github.accessTokenEnc);
      } catch (err) {
        this.d.log.warn({ err: errorMessage(err) }, `GitHub grant revoke failed during account deletion userId=${userId}`);
      }
    }

    await Promise.all([
      this.d.candidateProfiles.deleteByUserId(userId),
      this.d.fragments.deleteByUserId(userId),
      this.d.outcomes.deleteBySessionIds(sessionIds),
      this.d.preferences.deleteByUserId(userId),
    ]);
    await this.d.users.deleteCascade(userId);
    this.d.log.info(`account deleted userId=${userId}`);
    return true;
  }
}
```

```ts
  r.delete("/", async (req, res) => {
    const uid = userId(req);
    const input = parse(DeleteAccountBody, requiredBody(req), "invalid_request");
    enforceRateLimit(c.rateLimiters.loginPerIpEmail, `${clientIp(req)}|delete-account|${uid}`);
    const deleted = await c.accountDeletion.delete(uid, input);
    if (!deleted) {
      res.status(404).end();

    clearRefreshTokenCookie(res, c.config);
    res.status(204).end();
  });
```

```ts
"use client";

import { useCallback, useEffect, useState } from "react";

/** Settings → Accessibility. This device only (localStorage), applied as attributes on <html>. */
export interface DevicePrefs {
  reducedMotion: "system" | "reduce";
  textSize: "default" | "large";
}

export const DEVICE_PREFS_KEY = "iq-device-prefs";
export const DEVICE_PREFS_EVENT = "iq-device-prefs";
export const DEFAULT_DEVICE_PREFS: DevicePrefs = { reducedMotion: "system", textSize: "default" };

export function readDevicePrefs(): DevicePrefs {
  try {
    const raw = window.localStorage.getItem(DEVICE_PREFS_KEY);
    const parsed = raw ? (JSON.parse(raw) as Partial<DevicePrefs>) : {};
    return {
      reducedMotion: parsed.reducedMotion === "reduce" ? "reduce" : "system",
      textSize: parsed.textSize === "large" ? "large" : "default",
    };
  } catch {
    return DEFAULT_DEVICE_PREFS;
  }
}

export function applyDevicePrefs(prefs: DevicePrefs, root: HTMLElement = document.documentElement): void {
  if (prefs.reducedMotion === "reduce") root.dataset.motion = "reduce";
  else delete root.dataset.motion;
  if (prefs.textSize === "large") root.dataset.text = "large";
  else delete root.dataset.text;
}

export function writeDevicePrefs(patch: Partial<DevicePrefs>): DevicePrefs {
  const next = { ...readDevicePrefs(), ...patch };
  try {
    window.localStorage.setItem(DEVICE_PREFS_KEY, JSON.stringify(next));
  } catch {
    // Storage blocked (private mode): still apply for this page view.
  }
  applyDevicePrefs(next);
  window.dispatchEvent(new CustomEvent<DevicePrefs>(DEVICE_PREFS_EVENT, { detail: next }));
  return next;
}

/** The current device prefs plus a setter; stays in sync across components and tabs. */
export function useDevicePrefs(): [DevicePrefs, (patch: Partial<DevicePrefs>) => void] {
  const [prefs, setPrefs] = useState<DevicePrefs>(DEFAULT_DEVICE_PREFS);
  useEffect(() => {
    setPrefs(readDevicePrefs());
    const sync = () => setPrefs(readDevicePrefs());
    window.addEventListener(DEVICE_PREFS_EVENT, sync);
    window.addEventListener("storage", sync);
    return () => {
      window.removeEventListener(DEVICE_PREFS_EVENT, sync);
      window.removeEventListener("storage", sync);
    };
  }, []);
  const update = useCallback((patch: Partial<DevicePrefs>) => setPrefs(writeDevicePrefs(patch)), []);
  return [prefs, update];
}
```

```ts
const PREFS_KEY = SETTINGS_QUERY_KEYS.preferences;

export function usePreferences() {
  const { isAuthenticated } = useAuth();
  return useQuery<Preferences>({ queryKey: PREFS_KEY, queryFn: getPreferences, enabled: isAuthenticated, staleTime: 5 * 60_000 });

/**
 * Autosave one setting: optimistic, rolled back on failure. While several saves are in flight,
 * an earlier response doesn't overwrite later optimistic changes — only the last one to finish
 * writes the server's state into the cache.
 */
export function useUpdatePreferences() {
  const qc = useQueryClient();
  return useMutation({
    mutationKey: PREFS_KEY,
    mutationFn: (patch: PreferencesPatch) => updatePreferences(patch),
    onMutate: async (patch) => {
      await qc.cancelQueries({ queryKey: PREFS_KEY });
      const previous = qc.getQueryData<Preferences>(PREFS_KEY);
      if (previous) qc.setQueryData<Preferences>(PREFS_KEY, applyPatch(previous, patch));
      return { previous };
    },
    onError: (_err, _patch, ctx) => {
      if (ctx?.previous) qc.setQueryData(PREFS_KEY, ctx.previous);
      toast.error("Couldn't save that change. Please try again.");
    },
    onSuccess: (saved) => {
      if (qc.isMutating({ mutationKey: PREFS_KEY }) <= 1) qc.setQueryData(PREFS_KEY, saved);
      toast.success("Saved", { id: "settings-saved" });
    },
  });
}

export function useUpdateName() {
  const qc = useQueryClient();
  return useMutation({
    mutationFn: (name: string) => updateName(name),
    onSuccess: (user) => {
      qc.setQueryData<CurrentUser>(SETTINGS_QUERY_KEYS.currentUser, user);
      void qc.invalidateQueries({ queryKey: PROFILE_QUERY_KEYS.profile });
      toast.success("Name updated");

  });
```

```ts
import type { Preferences } from "@/features/settings";

type DateFormat = Preferences["locale"]["dateFormat"];
type TimeFormat = Preferences["locale"]["timeFormat"];

const pad = (n: number) => String(n).padStart(2, "0");

/** Today's date in the given format (the live example beside each option). */
export function formatDateExample(fmt: DateFormat, d: Date = new Date()): string {
  const dd = pad(d.getDate());
  const mm = pad(d.getMonth() + 1);
  const yyyy = String(d.getFullYear());
  if (fmt === "MM/DD/YYYY") return `${mm}/${dd}/${yyyy}`;
  if (fmt === "YYYY-MM-DD") return `${yyyy}-${mm}-${dd}`;
  return `${dd}/${mm}/${yyyy}`;
}

export function formatTimeExample(fmt: TimeFormat, d: Date = new Date()): string {
  if (fmt === "24h") return `${pad(d.getHours())}:${pad(d.getMinutes())}`;
  const h = d.getHours() % 12 || 12;
  return `${h}:${pad(d.getMinutes())} ${d.getHours() < 12 ? "AM" : "PM"}`;
}

/** "Asia/Kolkata" → "Asia / Kolkata". */
export function zoneLabel(tz: string): string {
  return tz.replaceAll("_", " ").split("/").join(" / ");
}

/** "GMT+5:30" for a zone right now; "" if the engine doesn't know it. */
export function offsetOf(tz: string, at: Date = new Date()): string {
  try {
    return new Intl.DateTimeFormat("en-US", { timeZone: tz, timeZoneName: "shortOffset" }).formatToParts(at).find((p) => p.type === "timeZoneName")?.value ?? "";
  } catch {
    return "";
  }
}
```

```tsx
"use client";

import { useId, useMemo, useState } from "react";
import { Check, ChevronsUpDown } from "lucide-react";
import { Input } from "@/components/ui/input";
import { Popover, PopoverContent, PopoverTrigger } from "@/components/ui/popover";
import { cn } from "@/lib/utils/cn";
import { offsetOf, zoneLabel } from "./format";

/** Rendering every IANA zone at once is wasteful; typing narrows the list. */
const MAX_SHOWN = 80;

export function TimezoneCombobox({
  value,
  onChange,
  ...aria
}: {
  value: string | null;
  onChange: (tz: string | null) => void;
  "aria-label"?: string;
  "aria-labelledby"?: string;
}) {
  const listId = useId();
  const detected = useMemo(() => Intl.DateTimeFormat().resolvedOptions().timeZone, []);
  const zones = useMemo(() => (typeof Intl.supportedValuesOf === "function" ? Intl.supportedValuesOf("timeZone") : [detected]), [detected]);
  const [open, setOpen] = useState(false);
  const [query, setQuery] = useState("");
  const q = query.trim().toLowerCase().replaceAll(" ", "_");
  const matches = useMemo(() => (q ? zones.filter((z) => z.toLowerCase().includes(q)) : zones).slice(0, MAX_SHOWN), [zones, q]);

  function pick(tz: string | null) {
    setOpen(false);
    setQuery("");
    if (tz !== value) onChange(tz);
  }

  const shown = value ?? detected;
  return (
    <Popover open={open} onOpenChange={setOpen}>
      <PopoverTrigger asChild>
        <button
          type="button"
          {...aria}
          className="flex h-9 w-full min-w-0 items-center gap-2 rounded-md border border-input bg-card px-3 text-left text-[13.5px] outline-none transition-colors hover:border-faint-2 focus-visible:ring-1 focus-visible:ring-ring sm:w-[300px]"
        >
          <span className="min-w-0 flex-1 truncate">{value ? zoneLabel(value) : `Automatic · ${zoneLabel(detected)}`}</span>
          <span className="flex-none font-mono text-[11px] text-faint">{offsetOf(shown)}</span>
          <ChevronsUpDown aria-hidden className="h-3.5 w-3.5 flex-none text-faint" />
        </button>
      </PopoverTrigger>
      <PopoverContent align="end" className="w-[min(320px,calc(100vw-2rem))] rounded-[12px] border-line-2 p-0">
        <div className="border-b border-line p-2">
          <Input
            autoFocus
            value={query}
            onChange={(e) => setQuery(e.target.value)}
            placeholder="Search timezones"
            aria-controls={listId}
            className="h-8 rounded-md"
            onKeyDown={(e) => {
              if (e.key === "Enter" && matches[0]) {
                e.preventDefault();
                pick(matches[0]);
              }
            }}
          />
        </div>
        <ul id={listId} role="listbox" aria-label="Timezones" className="m-0 max-h-[280px] list-none overflow-y-auto p-1">
          {q ? null : <ZoneOption selected={value === null} onSelect={() => pick(null)} label="Automatic" meta={zoneLabel(detected)} />}
          {matches.map((tz) => (
            <ZoneOption key={tz} selected={value === tz} onSelect={() => pick(tz)} label={zoneLabel(tz)} meta={offsetOf(tz)} />
          ))}
          {matches.length === 0 ? <li className="px-3 py-6 text-center text-[13px] text-muted-foreground">No timezone matches “{query}”.</li> : null}
        </ul>
      </PopoverContent>
    </Popover>
  );
}

function ZoneOption({ selected, onSelect, label, meta }: { selected: boolean; onSelect: () => void; label: string; meta: string }) {
  return (
    <li
      role="option"
      aria-selected={selected}
      tabIndex={0}
      onClick={onSelect}
      onKeyDown={(e) => {
        if (e.key === "Enter" || e.key === " ") {
          e.preventDefault();
          onSelect();
        }
      }}
      className={cn(
        "flex cursor-pointer items-center justify-between gap-3 rounded-[6px] px-2.5 py-1.5 text-[13px] outline-none hover:bg-accent focus-visible:bg-accent",
        selected && "text-foreground",
      )}
    >
      <span className="flex min-w-0 items-center gap-2">
        {selected ? <Check aria-hidden className="h-3.5 w-3.5 flex-none text-brand" /> : <span aria-hidden className="w-3.5 flex-none" />}
        <span className="truncate">{label}</span>
      </span>
      <span className="flex-none font-mono text-[11px] text-faint">{meta}</span>
    </li>
  );
}
```

```tsx
  open,
  onOpenChange,
  email,
  hasPassword,
}: {
  open: boolean;
  onOpenChange: (open: boolean) => void;
  email: string;
  hasPassword: boolean;
```
